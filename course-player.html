المستوى التأسيسي

🏆 مشروع التخرج: نظام إدارة المهام والمعدلات الذكي (Task & Grades Engine)

المشروع النهائي هو تتويج لكل ما تعلمته في المسار من هياكل بيانات، منطق برمجي، دوال، والتعامل مع الملفات. ستقوم ببناء تطبيق برمجي يعمل عبر سطر الأوامر (أو واجهة ويب بسيطة) لإدارة المهام الدراسية وحساب معدلات الطلاب مع حفظ البيانات في ملفات خارجية.

الميزات المطلوبة:

  • تسجيل دخول مستخدم وحفظ بياناته.
  • إضافة مهام دراسية مع تحديد مواعيدها وحالتها (مكتملة/غير مكتملة).
  • إدخال درجات المواد المختلفة وحساب المعدل التراكمي ونسب النجاح والرسوب.
  • تخزين وقراءة البيانات من ملف نصي أو JSON لضمان بقائها بعد إغلاق البرنامج.
  • واجهة تفاعلية بسيطة تعتمد على مدخلات المستخدم (Menus & Inputs).

المفاهيم المستخدمة:

  • **المتغيرات وأنواع البيانات**: لتخزين درجات المواد وأسماء المهام.
  • **الهياكل الشرطية والتكرار**: لعرض القوائم وفحص شروط النجاح والخيارات.
  • **الدوال (Functions)**: لتقسيم العمليات (حساب المعدل، قراءة الملف، كتابة المهمة).
  • **المصفوفات/القوائم**: لحفظ مجموعة المهام والدرجات المتعددة.
  • **التعامل مع الملفات**: لحفظ البيانات واسترجاعها تلقائياً.
طريقة التسليم البرمجية:

قم برفع المشروع على مستودع GitHub خاص بك، وتأكد من كتابة ملف README يوضح طريقة التشغيل ومميزات البرنامج، ثم شارك الرابط مع زملائك أو أضفه لمعرض أعمالك التقنية!
